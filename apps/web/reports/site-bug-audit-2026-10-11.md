# Проверка сайта — 11 октября 2026

| Приоритет | Сценарий                                                              | Ошибка и исправление                                                                                                                                           |
| --------- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| P2        | Публикация потребности с ошибкой зарплаты, формата работы или навыков | Мастер открывал шаг без ошибочного поля. Теперь открывается первый шаг; описание, город и часовой пояс ведут на второй. Проверено 11 тестами.                  |

Исправлен также проверочный скрипт авторизации: он принимает относительные URL редиректов и промежуточный переход через восстановление сессии.

## Выполненные проверки

- `npm test`: 140 файлов, 800 тестов прошли.
- `npm run typecheck`, `npm run lint`, `npm run build`: прошли.
- Проверки тестового API: 10 тестов прошли.
- Проверка серверной сессии: один запрос пользователя на рендер, свежая сессия на следующий запрос, изоляция пользователей, восстановление после ошибки, очистка после выхода.
- HTTP-проверка авторизации на production-сборке прошла: Origin, Content-Type, cookies, обновление страницы, refresh, безопасные редиректы, гостевой доступ, чужая роль, неверный refresh token, сбой 503 и восстановление, выход.
- 32 основных маршрута production-сборки вернули HTTP 200 без обнаруженного серверного сообщения об ошибке. Это проверка загрузки маршрутов, а не всех действий внутри страниц.

Маршруты: главная, справочник, вход, вход администратора, пять юридических документов; обзор кандидата, профиль, контакты, опыт, образование, навыки, готовность, согласия, задания, решения, тесты, предложения, опрос, ФСП; обзор работодателя, профиль компании, документы, сотрудники, потребности, кандидаты, предложения, задания, приглашение.

В браузере проверены справочник и фильтрация навыков, тестовый вход, обзор и форма профиля кандидата. При ширине 390 px справочник и кабинет не имели горизонтального переполнения. Статусы карточек входят в доступные имена ссылок. Главная и юридические страницы просмотрены, но полная проверка их интерактивности не завершена.

## Ограничения и оставшиеся проверки

- Использовался локальный синтетический API. Реальная интеграция ФСП, настоящие аккаунты, загрузка документов, публикация потребностей, принятие предложений и отправка решений не проверены end-to-end.
- Тестовый API не реализует часть методов onboarding, тестирования и заданий. Их сообщения об ошибке не записывались как дефекты продукта.
- Действия во всех разделах работодателя и администратора, страницы конкретных заданий/попыток/решений, все размеры экрана, темы и клавиатурные сценарии требуют отдельного ручного прохода.
- Браузерный инструмент заблокировал дальнейшие переходы. Ограничение не обходилось; оставшиеся основные маршруты проверены через HTTP.
- Dev-сервер во время проверки получил ENOSPC. Созданный для проверки временный кеш удалён, освободилось около 9 ГБ. Финальная HTTP-проверка выполнена на уже собранном production-приложении.

Успешные проверки не означают отсутствия других ошибок. Три функциональные ошибки подтверждены кодом и регрессионными тестами; исправления оставлены в рабочем дереве.
