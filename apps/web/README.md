# ФСП Скаут — веб-приложение

Платформа поиска работы и подбора IT-специалистов. Кандидат собирает профиль,
добавляет опыт, навыки и достижения ФСП, проходит тесты и отвечает на приглашения.
Работодатель управляет компанией, ищет кандидатов и публикует задания.
Административный интерфейс обслуживает справочники, тестирование и модерацию.

Этот документ описывает `apps/web`. Запуск API, базы данных, S3 и Keycloak описан
в [README монорепозитория](../../README.md).

## Быстрый запуск

Нужен Node.js 22.12+; Docker-сборка использует Node.js 24. Зависимости устанавливаются
из корня монорепозитория, где находится общий `package-lock.json`:

```sh
npm ci
cd apps/web
cp .env.example .env
npm run dev
```

Приложение доступно на `http://localhost:5173`. Для входа и работы с данными должны
быть запущены API и Keycloak. Команда `make setup` из корня также подготавливает
env-файлы, не перезаписывая существующие.

## Настройки

| Переменная            | Назначение                                   | Значение из `.env.example`                                       |
| --------------------- | -------------------------------------------- | ---------------------------------------------------------------- |
| `API_PROXY_TARGET`    | Origin API для серверных запросов и прокси   | `http://localhost:8080`                                          |
| `OIDC_TOKEN_URL`      | Адрес обновления токенов Keycloak            | `http://localhost:8180/realms/fsp/protocol/openid-connect/token` |
| `OIDC_CLIENT_ID`      | Клиент OIDC                                  | `fsp-web`                                                        |
| `APP_ORIGIN`          | Публичный origin приложения за reverse proxy | Не задан                                                         |
| `NEXT_PUBLIC_API_URL` | Базовый URL браузерного API-клиента          | `/api`, если не задан                                            |
| `FSP_DEV_DIST_DIR`    | Каталог результатов dev-сборки               | `.next-dev`, если не задан                                       |

После изменения серверных настроек перезапустите dev-сервер. Для production
пересоберите приложение: адрес API используется также в rewrites Next.js.
Не помещайте секреты в `NEXT_PUBLIC_*` и не коммитьте `.env`.

## Команды

Команды выполняются из `apps/web`.

| Команда                | Действие                               |
| ---------------------- | -------------------------------------- |
| `npm run dev`          | Dev-сервер на порту 5173               |
| `npm run build`        | Production-сборка в `.next`            |
| `npm run start`        | Запуск production-сборки на порту 3000 |
| `npm run typecheck`    | Проверка TypeScript                    |
| `npm run lint`         | ESLint, предупреждения запрещены       |
| `npm test`             | Однократный запуск Vitest              |
| `npm run test:watch`   | Vitest в режиме наблюдения             |
| `npm run format:check` | Проверка форматирования                |

Добавляйте зависимости из корня: `npm install <package> -w apps/web`.
