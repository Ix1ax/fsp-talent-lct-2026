## Design Context

### Users

Кандидаты заполняют профиль для поиска работы. В разделе опыта добавляют, проверяют, редактируют и удаляют места работы. Аудитория и сценарий заданы пользователем.

### Brand Personality

Сохранять текущий стиль кабинета. Нейтральный деловой тон выбран как рабочее предположение; отдельного изменения бренда пользователь не запрашивал.

### Aesthetic Direction

Использовать существующие карточки, типографику, семантические цвета и светлую/тёмную темы. На узких экранах поля и действия располагаются вертикально.

### Implementation Defaults

Существующий стек: Next.js App Router, React, TypeScript, Tailwind, локальные shadcn/ui-композиции через shared/ui (Radix, radix-nova), React Hook Form и Zod. Требования AGENTS.md имеют приоритет. Сохранять существующий стек и токены.

### Design Principles

- Показывать одну основную задачу: сохранить место работы.
- Располагать подписи над полями, ошибки рядом с полем; использовать связь aria-describedby.
- Сохранять черновик при ошибках API и переключении шагов.
- Объяснять причину недоступности действий: загрузка, отсутствие профиля, лимит записей.
- Отделять сохранение записи от обновления списка; порядок списка определяет сервер.
