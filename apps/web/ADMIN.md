# Админка фронтенда

Вход: `/admin`. Разделы: справочники, модерация навыков, банк заданий,
шаблоны тестов и администраторы (только для superadmin).

Используются существующие компоненты `shared/ui`, React Hook Form и Zod.
Структура FSD: `entities/admin` — контракт и API, `features/admin` — сессия,
запросы и формы, `widgets/admin-shell` — оболочка, `screens/admin` — экраны.

Запросы идут через существующий Next.js proxy `/api/v1/admin`.
`API_PROXY_TARGET` задаёт origin бэкенда (по умолчанию `http://localhost:8080`).
После изменения переменной перезапустите Next.js.

Историческая основа контракта — документы `admin-frontend.md` и
`admin-backend-extensions.md` от 8 октября 2026 года. Перед интеграцией проверяйте
админские маршруты в `/openapi.yaml` запущенного сервера: локальные копии схемы
могут отставать от развёрнутого API. Аккаунт superadmin создаётся настройками
бэкенда, универсального пароля нет.

Админская сессия хранится отдельно от Keycloak в sessionStorage текущей
вкладки. При восстановлении проверяется `/auth/me`; 401 защищённого запроса
очищает сессию. 403 оставляет сессию. Выход очищает локальные данные даже при
сетевом сбое, но в этом случае интерфейс сообщает об отсутствии подтверждения
отзыва токена на сервере.

Вопросы изменяются созданием полной новой версии. Шаблоны изменяются через
создание нового черновика из карточки. Публикация — отдельное действие.
Нехватка вопросов показывается для каждой строки состава с переходом к
отфильтрованному банку заданий. POST автоматически не повторяется.

Проверки: `npm test`, `npm run typecheck`, `npm run build` из `apps/web`.
Линтер исходников: `npx eslint src --max-warnings 0`.

Предпросмотр подключён по `admin-backend-extensions.md` от 8 октября 2026 года.
POST `/assessments/templates/{id}/previews` запускает тест с Idempotency-Key.
Ключ ожидающего запуска сохраняется в localStorage отдельно для аккаунта и шаблона;
повтор после сетевой ошибки использует тот же ключ. ID запущенного теста сохраняется
в URL `preview_id` и localStorage; перезагрузка восстанавливает GET вместо нового POST.
Вопросы и форма ответа берутся из снимка preview, правильные ответы до завершения
не загружаются. PUT сохраняет ответ, POST submit возвращает серверный результат.
Отсчёт использует server_time и performance.now(); дедлайн проверяет сервер.
Нельзя завершить тест с несохранёнными изменениями. Очистка уже сохранённого ответа
не поддерживается API: его можно заменить, либо отменить локальные изменения.
Нехватка банка блокирует запуск и показывает дефицит с переходом к заданиям.
DELETE удаляет пробное прохождение после подтверждения; после этого можно начать новое.
Результат учитывает серверный passed и баллы навыков, не пересчитывается на фронте.
Предпросмотры не создают кандидатские попытки; срок хранения на сервере — 7 дней.

Главный администратор может блокировать и включать обычные аккаунты через PATCH
`/admins/{id}`. Перед действием показывается подтверждение: блокировка отзывает
все сессии, включение требует нового входа. У superadmin кнопок статуса нет.

Новых переменных окружения фронта нет. До развёртывания фронта бэкенд должен
применить `20261008120000_admin_status_events.sql` и
`20261008121000_admin_assessment_previews.sql` и запустить API с новыми методами.
Код бэкенда и миграции в этой фронтенд-доработке не изменяются.

Меню сворачивается до иконок на desktop; предпочтение хранится в localStorage
под ключом `fsp.admin.sidebar`. Разделы сохраняют доступные названия и подсказки.
Фоновый узор использует существующие SVG бренда, отдельные варианты для
светлой и тёмной темы, и не перехватывает клики.

Карточки, создание и новые версии заданий и шаблонов, а также предпросмотр открываются на отдельных страницах `/admin/questions/...` и `/admin/templates/...`. Хлебные крошки возвращают к списку и карточке. Большие формы используют прокрутку страницы. Кнопка сворачивания закреплена в левом верхнем углу панели; её положение и высота пунктов меню не меняются при переключении.

При повторной загрузке того же ресурса предыдущие данные остаются видимыми; при смене фильтров или сессии они скрываются. Для загрузки, сброса фильтров и ошибок валидации зарезервировано место. Проверка пароля администратора использует ограничения API, но показывает понятные сообщения вместо байтов UTF-8.

На экранах уже 1024 px разделы закреплены снизу, а ссылка на сайт, тема и выход — в верхней панели. Контент учитывает нижнюю навигацию и safe area. Формы используют одну колонку на телефоне и несколько на планшете; варианты ответа и кнопки сохранения адаптируются к ширине. Проверены ширины 320, 360 и 768 px.

На широких мониторах рабочая область и верхняя панель занимают доступную ширину рядом с меню. Тексты предпросмотра ограничены удобной для чтения длиной строки.
