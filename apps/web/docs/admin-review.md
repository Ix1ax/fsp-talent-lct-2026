Автоматические проверки: 105 файлов тестов, 625 тестов; `npm run typecheck`, `npm run lint`, `npm run build`, `git diff --check` — успешно.

| Сценарий                                         | Результат                                                                                                                                                                                                   |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Компания: блокировка и разблокировка             | Пустая причина не отправляется; причина и дата появляются в карточке и исчезают после восстановления доступа                                                                                                |

Кабинеты кандидатов и работодателей в этой доработке не менялись: плашки здесь относятся к административным спискам и карточкам.

## Идентификация пользователей — 10 октября 2026

Подключены административные данные имени и почты, поиск, компании пользователя, идентификация участников компаний и авторов журнала. Данные обрабатываются только в административных экранах. При отсутствии имени и почты отображаются роль и стабильный ID; пользовательские имена не представлены как удостоверенная личность.

Проверено в браузере:

- Все 13 разделов загрузились с работающим backend на 8080; карточка пользователя загружает новые поля и связанные компании. Рабочие записи не изменялись.
- Ранее падавшая карточка `/admin/templates/b0000000-0000-4000-8000-000000000102` загрузилась с действующей административной сессией и показала опубликованный состав теста.
- Все 13 разделов на синтетическом API проверены на ширинах 320, 768, 1280 и 1920 px: ошибок загрузки и горизонтального переполнения нет.
- В раскрытых фильтрах банка заданий выбран навык с длинным названием. На всех четырёх ширинах контролы имеют высоту 44 px, на общей строке совпадают по вертикали и не перекрывают друг друга.
- Поиск по отдельной контактной почте приводит к нужному пользователю; карточка и диалог показывают имя, почту и ID.
- Разблокировка без причины не отправляется. С причиной обновляются кнопка и статус, прежняя плашка исчезает; повторная блокировка показывает новую причину.
- Компания заблокирована с длинной причиной без пробелов на ширине 320 px: текст переносится. Подтверждение компании и личные статусы её участников сохранены; связанная компания показывает блокировку отдельно от участия.
- Участники компании показывают поля административного контракта, причину блокировки аккаунта и независимый статус членства.
- Ошибка 503 отображается с кнопкой повторной загрузки; после восстановления тестового API список успешно обновляется.

Автоматические проверки: 108 файлов Vitest, 636 тестов; 10 тестов локального review API. TypeScript, ESLint, production build и `git diff --check` прошли. Дополнительные проверки покрывают nullable-идентичность, независимые статусы, поиск по обоим email и UUID, пагинацию связанных компаний и состав payload решений (имя и почта не передаются в запрос изменения доступа).

После переключения веток восстановлены зависимости из lock-файла и пересозданы устаревшие кеши Next.js; изменения зависимостей не потребовались.
