Исправления при проверке:

- Ошибки отдельных вариантов ответа теперь показываются рядом со строкой; ошибки группы вариантов также учитывают `root` React Hook Form.
- Во время сохранения формы справочников, аккаунтов и модерации блокируют поля.
- Навигация по вопросам предпросмотра на телефоне использует компактные строки с переносом.
- Устранён конфликт двух dev-серверов, использовавших общую `.next-dev`. Сервер на 5173 восстановлен с чистым кешем. Ссылка `/admin/templates/b0000000-0000-4000-8000-000000000102` отвечает HTTP 200 и загружается в браузере без runtime-ошибок; без авторизации показывает вход. Авторизованные карточки проверены на тестовых данных.

Автоматические проверки: 105 файлов тестов, 625 тестов; `npm run typecheck`, `npm run lint`, `npm run build`, `git diff --check` — успешно.

Эта проверка покрывает перечисленные состояния интерфейса и контракты. Она не заменяет проверку работы backend с рабочей базой и реальными административными решениями.
