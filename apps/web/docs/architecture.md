# Архитектура и сценарии

## Структура

| Каталог        | Ответственность                                              |
| -------------- | ------------------------------------------------------------ |
| `src/app`      | Маршруты App Router, layouts, metadata и обработчики Next.js |
| `src/screens`  | Композиция экранов и их состояние                            |
| `src/widgets`  | Оболочки кабинетов, хэдер, футер и общие блоки               |
| `src/features` | Действия пользователя, формы и управление запросами          |
| `src/entities` | Доменные типы, API и представления сущностей                 |
| `src/shared`   | API-клиенты, UI, hooks, утилиты и константы                  |
| `public`       | SVG, брендовые изображения и видео                           |

Импорты из `src` используют алиас `@/`. Публичный интерфейс сегмента определяется
его `index.ts`. Серверные API экспортируются отдельно через `api/server.ts`:
их нельзя импортировать в клиентские компоненты через общий barrel.
Словари находятся в `shared/contants` — это существующее имя каталога.

## Маршруты и оболочки

| Маршрут                                           | Назначение                                                                 |
| ------------------------------------------------- | -------------------------------------------------------------------------- |
| `/`                                               | Лендинг поиска работы                                                      |
| `/login`, `/auth/callback`                        | Вход и возврат из OIDC                                                     |
| `/cabinet`                                        | Входная точка кабинета                                                     |
| `/candidate` и разделы профиля                    | Профиль, согласия, контакты, опыт, образование, навыки, готовность         |
| `/candidate/survey`, `/candidate/fsp`             | Анкета и достижения ФСП                                                    |
| `/candidate/assessments`                          | Доступные тесты и история попыток                                          |
| `/candidate/assessments/[attemptId]`              | Прохождение и результат теста                                              |
| `/candidate/offers`                               | Приглашения работодателей                                                  |
| `/candidate/tasks`, `/candidate/task-submissions` | Задания и отправленные решения                                             |
| `/employer` и вложенные разделы                   | Компании, документы, команда, потребности, кандидаты, предложения, задания |
| `/admin` и вложенные разделы                      | Отдельный административный интерфейс                                       |
| `/guides`, `/legal`                               | Справочники и юридические документы                                        |

Полный перечень путей и генераторы ссылок находятся в
[`routes.ts`](../src/shared/contants/routes.ts).
Группы `(site)` и `(workspace)` организуют layouts, но не входят в URL.
Страницы сайта используют `AppHeader` и `SiteFooter`; у логина отдельный layout
без хедера и футера. Корневой layout подключает тему, подсказки, уведомления,
восстановление сессии и защиту несохранённых данных.

## Основные сценарии

Кандидат даёт согласия, заполняет профиль и выбирает статус поиска.
Готовность и разрешение публикации определяются сохранёнными серверными данными;
локальный черновик не подтверждает выполнение чек-листа. Профиль можно дополнить
достижениями ФСП, импортом резюме и результатами тестирования, экспортировать в PDF.

В тестировании название включает стек, специализацию и грейд. Перед запуском
показываются выбранный тест и ограничения. Попытка создаётся после подтверждения;
дедлайн и результат определяет сервер. Сохранение ответов и восстановление попытки
реализованы в `features/assessment-runner`.

Работодатель управляет компанией, её документами и участниками, формирует
потребности и просматривает банк кандидатов. Приглашения и доступ к контактам
проходят через соответствующие API; интерфейс не должен раскрывать контакты
самостоятельно. Задания включают файлы, решения кандидатов и проверку результата.

Администратор управляет справочниками, модерацией, заданиями и шаблонами тестов.
Админские права и сессия отделены от ролей кандидата и работодателя.

## Дизайн и взаимодействия

Цвета, радиусы, шрифты и ширина контейнера заданы в `src/app/globals.css`.
Используйте компоненты `shared/ui` и семантические цвета вместо новых вариантов
кнопок или карточек. Панели используют `rounded-xl`, кнопки — `rounded-lg`.
Лендинг сохраняет собственную композицию и inline Tailwind-классы.

Общие анимации находятся в `shared/ui/motion`. Учитывайте
`prefers-reduced-motion`, доступность с клавиатуры и сохранение фокуса при переходах.
Логотипы и фавиконка находятся в `public/brand`; фоновые ролики — в `public/videos`.
