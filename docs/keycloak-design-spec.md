# Keycloak — дизайн ФСП Скаут

Обновлено 11 октября 2026. Используется новый набор логотипов из коммита фронта `aac31e3`, вошедшего в `main` через `356852a`. Источник оформления — текущий фронт после слияния: `AuthLayout`, `BrandPattern`, `PageWrapper` (вариант `auth`), `Input`, `Button`, `ThemeToggle` и токены `globals.css`.

## Бренд и ресурсы

Название продукта — **ФСП Скаут**. В импортах realm и скрипте применения темы обновлены название realm и имя отправителя писем. Скрипт также обновляет `displayNameHtml`, чтобы старое название не оставалось в HTML-представлении realm.

Используются готовые SVG из `apps/web/public/brand/`:

| Ресурс | Применение |
| --- | --- |
| `scout-horizontal-on-light.svg` | Логотип для светлой темы |
| `scout-horizontal-on-dark.svg` | Логотип для тёмной темы |
| `scout-mark-on-light.svg` | Повторяющийся фирменный фон светлой темы |
| `scout-mark.svg` | Повторяющийся фирменный фон тёмной темы |
| `favicon.svg` | Значок вкладки |

Копии находятся внутри `infra/keycloak/themes/fsp-scout/login/resources/img/brand-aac31e3/`. Keycloak загружает логотипы, фон, CSS, JS и локальный Onest самостоятельно, без зависимости от работающего фронта. Горизонтальные логотипы и favicon совпадают с файлами фронта; знаки для фона скопированы из той же папки.

## Композиция

- Фон занимает всё окно. Знак повторяется с размером плитки 300 × 350 px, размытием 3 px и прозрачностью 0,035 в светлой / 0,015 в тёмной теме.
- По центру — вертикальная колонка. Максимальная ширина карточки 448 px; на мобильном экране внешние отступы 16 px. Длинные формы увеличивают высоту страницы и прокручиваются.
- Над карточкой находится горизонтальный логотип высотой 28 px в области высотой не менее 44 px. Интервал между логотипом, карточкой и возвратом на главную — 32 px.
- Переключатель темы 40 × 40 px находится в верхнем правом углу: отступ 16 px на мобильных и 24 px от 640 px.
- Карточка: фон `card`, граница 1 px `border`, радиус 18 px, без тени. Внутренние отступы 24 px на мобильных и 32 px от 640 px.
- Ссылка «← На главную» расположена по центру под карточкой. Адрес берётся из существующего `WEB_PUBLIC_URL`.

## Типографика и элементы

| Элемент | Оформление |
| --- | --- |
| Шрифт | Onest, локальный variable TTF |
| Заголовок | 24 / 32 px, вес 600 |
| Описание | 15 / 24 px, цвет `muted-foreground`, отступ 8 px |
| Обычный текст и label | 14 / 20 px, label с весом 500 |
| Поля | Высота 40 px, радиус 10 px, граница `input`, фон `background` |
| Текст поля | 16 px на мобильных; 14 px от 768 px |
| Основная кнопка | Высота не менее 44 px, ширина всей формы, радиус 10 px, вес 600 |
| Фокус | Граница `ring`, кольцо 3 px; видимый фокус для клавиатуры |
| Ошибка | Цвет `destructive`, сообщение у поля и `aria-describedby` |

Форма входа: почта, пароль с переключателем видимости, восстановление, кнопка входа. Регистрация отделена линией и отступом. Если realm включает «Запомнить меня», этот элемент сохраняется.

Регистрация, восстановление и смена пароля используют те же размеры и общий шаблон. Набор полей и обязательных действий определяет Keycloak. В текущем локальном registration flow вводятся почта, имя и фамилия; установка пароля выполняется согласно настройкам процесса.

## Установка и обновление

Тема называется `fsp-scout`. Новый CSS — `css/fsp-scout-20261011-v3.css`: отдельное имя исключает использование ранее закешированного старого оформления. Логотипы, фоновые знаки и favicon находятся в отдельном каталоге `img/brand-aac31e3/`: новый путь заставляет браузер загрузить актуальный набор SVG вместо закешированных старых копий.

Для существующего realm:

```sh
docker compose up -d --no-deps keycloak
docker compose restart keycloak
sh scripts/keycloak-theme.sh
```

Если после переключения ветки смонтированный каталог темы пуст внутри контейнера, повторно подключить его:

```sh
docker compose up -d --no-deps --force-recreate --wait keycloak
sh scripts/keycloak-theme.sh
```

Для серверного деплоя уже настроены копирование ресурсов в CI, перезапуск Keycloak и вызов `keycloak-theme.sh` в `deploy-server.sh`. Скрипт обновляет только оформление и брендинг через стандартный merge `kcadm`: остальные настройки realm и SMTP сохраняются.

Новые переменные окружения и миграции БД не нужны. Используется существующий `WEB_PUBLIC_URL` — адрес фронта конкретного окружения. API, клиенты, пароли и Authorization Code + PKCE не менялись.

## Проверка

Проверено в локальном Keycloak 26.8.0:

- Переход с работающего фронта `localhost:5173/login` открывает тему ФСП Скаут.
- Вход, регистрация и восстановление отображаются с общим оформлением.
- Светлая и тёмная темы переключаются; правильный логотип и фон меняются вместе с палитрой.
- Ошибка входа с вымышленными данными, обязательные поля регистрации и пустой запрос восстановления отображают серверные ошибки; после ошибки кнопки доступны для повторной отправки.
- Переключатель показа пароля меняет тип поля и доступную подпись, не отправляя форму.
- На 320 px длинная регистрация полностью доступна при прокрутке, горизонтального переполнения нет. На 390 px поля используют 16 px, карточка имеет ширину 358 px.
- `scripts/keycloak-smoke.sh`: существующий тестовый вход Keycloak → JWT → API успешен.
- JSON realm, shell-скрипт и `git diff --check` проходят проверку.

Почтовые ссылки подтверждения и полный процесс установки нового пароля в этой проверке не проходились.
