## Исправления

1. Добавлена пагинация списка компаний; переключатель компании по-прежнему получает все компании. Проверен выход загрузчика за первую порцию API из 100 записей.
2. В списках API без `total` запрашивается 21 запись, отображается 20. Дополнительная запись определяет наличие следующей страницы. Следующий запрос идёт с offset + 20, поэтому дополнительная запись не теряется.
3. Общая пагинация возвращает пользователя с пустой страницы после изменения списка. Проверено живым просмотром последнего кандидата: 81 → 80 записей.
4. Подборка кандидатов в карточке потребности использует ту же общую пагинацию: она сохраняет возможность возврата при уменьшении списка.
5. Загрузчики полного списка потребностей учитывают `hasMore`; поиск и фильтры работают по всей выдаче.
6. Статус проверки компании обновляется после изменения документов, поскольку удаление доказательств может инвалидировать заявку на бэкенде.
7. Подписи основной навигации скрываются раньше: при ширине 1024–1535 px остаются иконки; с 1536 px видны подписи. На экранах до 480 px второй ряд также показывает иконки. Ссылки имеют доступные названия и подсказки. Проверены 390, 1024, 1280 и 1536 px, светлая и тёмная темы.

## Повторное наполнение

Скрипт `scripts/seed-employer-pagination-qa.py` работает только с локальным Docker-контейнером `fsp-postgres-1` и S3 на `127.0.0.1:8333`. Требует существующую QA-компанию с владельцем, готовым документом и заданием с файлом. Использует детерминированные ID и `ON CONFLICT DO NOTHING`; повторное выполнение не дублирует записи. Читает настройки S3 из корневого `.env`, не выводит секреты.

```bash
# Сначала проверить план без записи:
python3 scripts/seed-employer-pagination-qa.py --company-id 0b4af3ee-c7ed-4621-8197-5b8357fdbc7c

# Наполнить локальную QA-компанию:
python3 scripts/seed-employer-pagination-qa.py --company-id 0b4af3ee-c7ed-4621-8197-5b8357fdbc7c --apply
```

Исторические задания занимают разные даты публикации; правило одной публикации в день не изменялось. Повторный запуск не сбрасывает зафиксированные просмотры или другие действия проверки.
